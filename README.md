Игра на питоне на:
- python arcade-3.0.1 library
- pyzmq-26.2.1 zmq-0.0.0
  
## Описание геймплея ##
Доступно несколько режимов игры:
- Для двоих на одном компьютере
- Для 2-4 игроков в локальной сети

## Установка ##
Скачайте и распакуйте архив
```
cd 2-md-15-ShtonDeLon-master
```
```
pip install arcade
```

## Запуск игры ##
Запустите игру
```
python console_menu.py
```
Далее выберите первый формат игры:
```
1. Создать PvP игру на одном компьютере
2. Создать игру в локальной сети
3. Подключиться к игре в локальной сети
```
PvP игра запустится в одном окне.

## Запуск игры по сети ##
После запуска игры выберите второй формат игры:
```
1. Создать PvP игру на одном компьютере
2. Создать игру в локальной сети
3. Подключиться к игре в локальной сети
```
Затем выберите количество игроков от 2 до 4:
```
Введите количество игроков в сети (2-4):
```
Запустится окно хоста. игра встанет на паузу.
Затем на другом устройстве также запустите игру и выберите: 
```
3. Подключиться к игре в локальной сети
```
Затем введите ip-адрес хоста. Он находится в названии окна у хоста
```
Введите ip-адрес игры (формат: 192.168.0.0:0000)
(ip и доступные порты вы можете узнать в окне хоста игры):
```
Откроется окно игры и игра запустится.
